# 化学物質法令チェック台帳

工場内で使用・消費する化学品について、日本の関係法令の該当判定と、年間の点検・測定・健診・届出タスクの管理を行う **1ファイル完結の Web アプリ** です。

- 実体は `chemical-compliance.html` の1ファイルのみ（物質マスタを外部CSVから参照させることも可能）
- サーバー不要・インストール不要・外部ライブラリ不要（Webフォント以外の通信をしません）
- ダブルクリックでブラウザが開けば動きます

## 使い方（3ステップ）

1. `chemical-compliance.html` をブラウザで開く
2. **事業場の条件**タブで、従業員数・敷地面積と設備の有無にチェックを入れる
3. **化学品台帳**タブで、SDS の第1項・第3項・第15項を写す（CAS番号を入れると成分名が自動で入ります）

これだけで、該当法令・年間チェック表・期限が自動で組み上がります。以後は実施日を1つ入れるたびに次回期限が繰り上がります。

## 何が自動化されるか

| 入力 | 自動で出てくるもの |
|---|---|
| CAS番号と含有率 | 特化則・有機則・化管法・毒劇法・水濁法などの該当区分 |
| 年間取扱量 | 物質別の年間取扱量と PRTR 届出の要否 |
| 消防法品名と貯蔵量 | 指定数量の倍数、少量危険物／許可対象の判定 |
| 事業場の条件 | 選任・届出・測定・点検・健診の義務一覧と期限 |

## 収録法令（23）

労働安全衛生法／特定化学物質障害予防規則／有機溶剤中毒予防規則／鉛中毒予防規則／粉じん障害防止規則／じん肺法／石綿障害予防規則／作業環境測定法／女性労働基準規則／化管法（PRTR・SDS）／毒物及び劇物取締法／消防法／化審法／廃棄物処理法／水質汚濁防止法／下水道法／大気汚染防止法／土壌汚染対策法／フロン排出抑制法／PCB特別措置法／高圧ガス保安法／化学兵器禁止法／自治体条例

## 書き出し

- チェック表 CSV（BOM付きUTF-8。Excelで文字化けしません）
- 物質別判定 CSV
- 年間予定 ICS（Googleカレンダーの「設定 → インポート」で取り込み）
- 全データ JSON（バックアップ・PC間の引き継ぎ・担当者交代時）
- 印刷 / PDF（立入検査でそのまま提示できる体裁）

## データの保存場所

入力内容は**開いているブラウザの localStorage** に保存されます。サーバーには送信されません。
別の PC や担当者と共有するときは JSON で書き出して受け渡してください。

## 成分が非開示の製品

実務では、SDSに「その他」「企業秘密」としか書かれていない製品が少なくありません。CAS番号からは判定できないため、**法令ごとに「該当物質が含まれているか」を供給者に確認し、その回答で判定する**経路を用意しています。

化学品台帳の各製品に「供給者への確認結果」があり、15の法令区分について **含有あり／含有なし／未回答** を記録します。含有ありにすると、成分が未入力でもその法令の義務が立ち上がります。

| 確認する区分 | 含有率の回答 |
|---|---|
| 安衛法 ラベル表示・SDS交付・リスクアセスメント対象物 | 必要（裾切り1%または0.1%） |
| 皮膚等障害化学物質等／がん原性物質 | 不要 |
| 特定化学物質（第1類〜第3類）／うち特別管理物質 | 必要（原則1%超） |
| 有機溶剤／うち第1種・第2種 | 必要（合計5%超） |
| 鉛／粉じん則の対象物 | 不要 |
| 化管法の指定化学物質／うち特定第一種 | 必要（1%・0.1%以上） |
| 毒物・劇物／水濁法の有害物質／有害大気汚染物質／化審法の第一種特定化学物質 | 不要 |

**「含有あり／なし」だけでは決まらない判定があります。** 化管法の年間取扱量1t、特化則の1%超、有機則の5%超は含有率が要るため、未回答のときは要確認として残ります。化管法の届出は物質ごとの数量が要るので、該当物質の名称と含有率まで確認して成分欄に登録してください。

「書き出し」タブの**含有調査依頼書**（CSV）で、製品ごと・法令ごとの質問票を出せます。既に得ている回答は転記済みなので、空欄だけ埋めてもらえば足ります。

## 物質マスタ

CAS番号を法令区分に読み替えるための辞書です。**211物質**を内蔵しています。

| 法令 | 収録数 | 備考 |
|---|---|---|
| 特化則 | 78 | 第1類7・第2類63・第3類8。うち特別管理物質50 |
| 有機則 | 44 | 第1種2・第2種35・第3種7（**現行の全数**） |
| 化管法 | 102 | 第一種・特定第一種・第二種 |
| 毒物・劇物 | 90 | |
| 消防法 危険物 | 110 | 品名と指定数量つき |
| がん原性物質 | 67 | |

特化則・有機則・鉛則のように**対象が閉じているリストは全数**を収録しています。

### 内蔵マスタだけでは足りません

労働安全衛生法のラベル表示・SDS交付・リスクアセスメントの対象物は、令和6年4月以降に段階的に拡大し、**令和8年4月には約2,900物質**になります。化管法の指定化学物質も第一種515・第二種134あります。内蔵しているのは、工場で実際に使われる代表物質と、対象が閉じているリストです。

そのため「物質マスタ」タブから**公式リストをCSVで参照・取り込み**できるようにしてあります。

### 参照方式

**HTMLと同じフォルダに置いておけば、起動時に自動で読み込みます。**

| 置くファイル | 読み込まれる場面 |
|---|---|
| `chem-master.csv` | サーバから配信しているとき（社内サーバ・イントラネット） |
| `chem-master.js` | **ファイルを直接開いたとき（ダブルクリック）** |

内容は同一です。**両方置いておけば環境を問わず動きます。** 2つある理由は、`file://` で開いたページからは CSV の読み込みがブラウザに拒否され、スクリプトの読み込みだけが許されるためです。どちらも `tools/build_master.py` が生成し、リポジトリに同梱しています。

他の取り込み方法：

| 方式 | 手順 |
|---|---|
| **URL指定で取得** | 「マスタの参照元」にURLを入れる。起動時に自動で再取得 |
| **ドラッグ&ドロップ** | CSVを物質マスタ画面に落とす |
| **ファイル選択** | 「CSVで取り込み」ボタン |

自動参照ぶんは起動のたびに入れ替わるため、**置いてあるファイルを更新すれば全PCのマスタが揃います**。手で取り込んだ物質はそのまま残るので、共通マスタと自社固有物質を併用できます。取得に失敗したときは、前回取り込んだ内容のまま動作を続けます。

**外部サイトの直接参照はできません。** 厚生労働省やNITEのサイトをブラウザから直接読むことは、CORS が許可されていないため、どの環境でも技術的に不可能です。次の更新スクリプトを使ってください。

### アプリ上でマスタを作る（Python不要）

公式サイトからダウンロードした **Excel（.xlsx）をそのまま**「物質マスタ」タブに放り込めます。追加のソフトは要りません。ZIPの展開もブラウザの標準機能で行っています。

1. ファイルをドラッグするか「Excel・CSVを取り込み」で選ぶ
2. **確認画面**が出る。CAS番号の列・物質名の列・見出し行は自動で検出され、違っていれば選び直せる
3. 「この表に載っている物質すべてに設定する区分」を選ぶ（例：化管法の第一種指定化学物質の一覧なら **化管法＝第一種**）
4. **新規◯件 / 既存を更新◯件** と、書き換わる項目名を確認してから取り込む
5. 「マスタをCSVで書き出し」「chem-master.js で書き出し」で配布用ファイルを作る

前置きの説明行や注記行が混じっていても読めます。「変更しない」にした項目は既存の値がそのまま残るため、法令ごとの一覧を順に重ねていけます。

### NITE-CHRIPの法規制一覧を統合する

[NITE-CHRIP](https://www.chem-info.nite.go.jp/chem/chrip/chrip_search/systemTop) から法規制の該当一覧をExcelで出力し、物質マスタへ統合できます。

```bash
python3 tools/build_master.py                      # 内蔵シード chem-master-seed.csv を生成
python3 tools/merge_chrip.py CHRIP.xlsx \
    --base chem-master-seed.csv --out chem-master.csv --js chem-master.js
```

**既存の細かい区分を壊しません。** CHRIPの一覧は該当（●）／非該当（-）の二値で、特化則の第1類〜第3類、有機則の第1種〜第3種、化管法の第一種・第二種までは持ちません。そのまま取り込むと内蔵マスタの区分が失われるため、**既存の値を優先し、空いているところだけをCHRIPで埋めます**。

区分が分からないまま該当だけ判明したものは `?` を入れ、その物質を使ったときに**「特化則の区分が未確定」「有機則の種別が未確定」として要確認**に上がります。特別管理物質かどうか（30年保存）、第1種・第2種かどうか（作業環境測定と特殊健診）が変わるため、黙って確定させません。

実測（7,117行のCHRIP出力の場合）：

| | 件数 |
|---|---|
| 統合後の収録 | **6,933物質**（新規6,722／既存に照合179） |
| 安衛法 表示・通知対象物 | 6,924（非該当7・要確認2は内蔵マスタ側の値） |
| 埋まった 皮膚等障害 | 2,528 |
| 埋まった 特化則 | 1,450（すべて区分未確定） |
| 埋まった 化管法 | 4,201（すべて要確認） |
| 埋まった 安衛法危険物 | 663 |
| 埋まった 濃度基準値 | 268 |
| 埋まった がん原性 | 266 |
| 読み込み | 656ms ／ CSV 1.1MB |

**安衛法の「表示・通知対象物」の列はCHRIPの出力に現れません。** CHRIPで安衛法の対象物質に絞って出力した場合、絞り込み条件そのものなので列にならないためです。その場合は `--anzen all` を付けると全行を対象物として取り込みます。

```bash
python3 tools/merge_chrip.py CHRIP.xlsx --base chem-master-seed.csv \
    --out chem-master.csv --js chem-master.js --anzen all
```

絞らずに出力した一覧の場合は既定の `auto` を使ってください。特化則・有機則・がん原性・濃度基準値・皮膚等障害のいずれかに該当する物質を「対象物」、判断材料がないものを「要確認」とします。実際に使う物質だけが要確認として上がります。

### 濃度基準値について

**特化則・有機則の対象物質には、濃度基準値が設定されていないことがあります。** 実データでもトルエン（有機則第2種）とベンゼン（特化則）には付いておらず、4-tert-ブチルトルエンや2,4,6-トリニトロトルエン、ニトロベンゼンといった**誘導体の側**に設定されています。

特化則・有機則の対象物質には、これとは別に**管理濃度に基づく作業環境測定**が義務として残ります。データの欠落ではないので、そのまま取り込んで差し支えありません。

### 安衛法の個別リスト（製造禁止・製造許可・変異原性・濃度基準値）を取り込む

CHRIPの一覧には、**製造等禁止物質・製造許可物質・強い変異原性が認められた化学物質**の別や、**濃度基準値の実際の数値**が入っていません。これらは別の一覧として配布されているため、`tools/merge_anzen_lists.py` でCHRIP統合済みのマスタに重ねます。

```bash
python3 tools/merge_anzen_lists.py --base chem-master.csv --out chem-master.csv --js chem-master.js \
    --ban  製造等が禁止される有害物等.xlsx \
    --perm 製造の許可を受けるべき有害物.xlsx \
    --muta 強い変異原性が認められた化学物質.xlsx \
    --noudo noudokijyun_r050427_1.xlsx:令和6年4月1日 \
    --noudo noudokijyun_r060508.xlsx \
    --noudo noudokijyun_r081001.xlsx
```

`--ban` `--perm` `--muta` はCHRIPで各カテゴリに絞って出力したxlsx（`一般情報：CAS RN` と `一般情報：物質名称` の列を使います）。`--noudo` は厚生労働省が告示ごとに公表している濃度基準値一覧のxlsx（シート「濃度基準値等」）です。告示が新しい順に上書きされるよう、**古い告示から順に**指定してください。`FILE:ラベル` の形で適用期日を補えます（適用期日の列を持たない第1弾の一覧用）。

実測値です。

| 取り込み | 該当 | うち新規 |
|---|---|---|
| 製造禁止 | 14 | 5 |
| 製造許可 | 329 | 1 |
| 強い変異原性 | 1,403 | 1,246 |
| 濃度基準値 | 288 | 14 |
| **統合後の収録** | **8,199物質** | |

| 適用期日別の濃度基準値 | 件数 |
|---|---|
| 令和6年4月1日 | 81 |
| 令和7年10月1日 | 121 |
| 令和8年10月1日 | 84 |

**製造許可物質は特化則の第1類物質と同じ範囲です**（安衛法第56条・令第17条・別表第3第1号）。そのためCHRIP由来で「区分未確定（`?`）」だった物質のうち329件が**第1類に確定**し、未確定は1,450件から1,136件に減りました。

**セル結合を追います。** 濃度基準値の一覧には、同じ物質名の下にCAS番号だけが並ぶ行（「すず及びその化合物（…に限る。）」など）や、1行に複数のCAS番号がカンマ区切りで入る行（トルイジン、弗素及びその水溶性無機化合物、モリブデン及びその化合物）があります。前者は直前の行から物質名と適用期日を引き継ぎ、後者はCAS番号ごとに分けて登録します。

**製造禁止物質のうち2件は物質そのものが禁止ではありません。** ベンゼン（71-43-2）は「ベンゼンを含有するゴムのり（重量の5%超）」、黄りん（12185-10-3）は「黄りんマッチ」が禁止の対象です。マスタの備考にその旨を入れてあります。

**強い変異原性の一覧から新しく増える1,246物質は、安衛法の列を「要確認」にします。** 変異原性指針の対象は既存化学物質の変異原性試験などで見つかったもので、表示・通知対象物とは範囲が一致しないためです。`--anzen all` で全件を対象物にすることもできます。

なお変異原性指針は法令上の義務ではなく**行政指導としての指針**です（平成5年基発第312号の2）。ばく露低減、作業環境測定、労働衛生教育、有害性の周知、作業記録の30年保存を求めています。

### NITEの化審法マスター辞書を取り込む

NITEが公開している[一般化学物質等製造（輸入）実績等届出書作成支援ソフトの辞書ファイル](https://www.nite.go.jp/chem/kasinn/ippan_todokede/jisyo04.html)を変換して、**約6万3千物質のCAS番号と日本語名称の辞書**として使えます。

```bash
python3 tools/convert_nite_jisho.py MasterJisho.xlsx --out chem-master.csv --js chem-master.js
```

Ver16.00.00.00 での実測値です。

| 項目 | 値 |
|---|---|
| 元ファイル | 108,331行 / 6.2MB |
| 変換後 | **63,351物質**（CAS番号なし30,091行を除外、重複14,887行を先頭採用） |
| 出力 | CSV 6.1MB / JS 6.5MB |
| 読み込み | ページ表示から **527ms** でマスタ構築完了 |

**取り込むのはCAS番号と官報公示名称の対応だけです。** 辞書に含まれる「物質区分」の数値コード（1〜4）は、対応する化審法の区分が公式資料で確認できなかったため取り込みません。誤った区分で法令判定を動かすより、既存マスタの値を残すほうが安全なためです。

安衛法・化管法・消防法・毒劇法の区分はこの辞書に含まれていません。それらは別途、各省庁の一覧を取り込んでください。

`--columns std` を付けると官報公示整理番号を備考欄に入れられますが、内蔵マスタの注記を上書きするため既定では付けていません。

### 大量の辞書の扱い

同フォルダやURLから読み込んだ分は、**ブラウザに保存せず起動のたびに読み直します**。数万件の辞書でも保存領域を圧迫しません。手で取り込んだ物質は従来どおり保存されます。

優先順位は 内蔵マスタ → 外部辞書 → 手で取り込んだ物質 の順で、手入力が最優先です。外部辞書がCAS番号と物質名しか持たない場合、内蔵マスタの法令区分はそのまま残ります。

### コマンドでマスタを更新する

`tools/update_master.py` が、官公庁が公開している一覧（Excel / CSV）を `chem-master.csv` に反映します。標準ライブラリだけで動くため、追加のインストールは不要です。

```bash
# 労働安全衛生法の表示・通知対象物質一覧を反映
python3 tools/update_master.py --add 安衛法一覧.xlsx --set 安衛法=対象物 --source "安衛法 令和8年4月"

# 化管法の指定化学物質を反映
python3 tools/update_master.py --add prtr1.xlsx --set 化管法=第一種
python3 tools/update_master.py --add prtr2.xlsx --set 化管法=第二種
```

`chem-master.csv` と `chem-master.js` の両方を書き出すので、HTMLと同じフォルダに置き換えてください。`--dry-run` で結果だけ確認できます。

**列の並びに依存しません。** 前置きの説明行や注記行が入っていても、CAS番号らしい値が最も多い列を自動で見つけます。省庁の様式は改正のたびに変わるため、ヘッダー名では判定していません。

**既存の情報は壊しません。** `--set` で指定した列だけを書き換え、特化則・有機則・消防法・毒劇法などの既存の値はそのまま残します。

**ファイルの入手は人が行います。** ダウンロードURLは改正のたびに変わるため、スクリプトに埋め込むとかえって壊れやすいからです。入手先はスクリプトの冒頭に記載しています。

### 自動化できない部分

消防法の品名・指定数量と、毒物及び劇物の指定は、**CAS番号ではなく品名で公開されている**ため、機械的な突き合わせができません。これらの列は内蔵マスタの値を使い、追加分はSDS第15項を見て手で埋めてください。

### 手動での取り込み

1. 「マスタをCSVで書き出し」で現在の形式を出力
2. Excel で行を追加・修正
3. 「CSVで取り込み」で戻す（CAS番号が一致する行は上書き、無い行は追加）

取り込んだ物質は内蔵側より優先されます。書き出し→取り込みの往復で全211物質・全19項目が一致することを確認済みです。

入手先は画面内の「公式リストの入手先と取り込み手順」に記載しています（厚生労働省 職場のあんぜんサイト、NITE-CHRIP、化管法政令、消防法別表第一、毒物及び劇物指定令）。

マスタにない物質・区分が確定しない物質は、黙って「対象外」にはならず、**要確認としてチェック表に残り続けます**。

### マスタの生成

内蔵マスタは `tools/build_master.py` から生成し、`chemical-compliance.html` に注入しています。手書きによる転記ミスを避けるためのもので、アプリ本体は単一HTMLのままです。

```

```

## 物質を1件ずつ登録する（登録ウィザード）

物質マスタに無い物質や、区分が未確定の物質を、**法令をひとつずつ確認しながら**登録できます。タブ06の「物質を1件ずつ登録」、または法令該当判定の要確認欄に出る「この物質を登録する」から開きます。物質マスタの各行の「確認・編集」で既存の物質を開き直すこともできます。

各画面には**SDS第15項にこう書かれていれば該当する**という表記例が並びます。SDSを見ながら該当・非該当を選ぶだけで終わります。

```
1  物質の特定        CAS番号・物質名（既存なら現在の登録内容が埋まります）
2  安衛法            表示・通知対象物 / 皮膚等障害 / がん原性 / 濃度基準値 /
                     危険物 / 製造等禁止 / 製造許可
3  変異原性指針      強い変異原性
4  特化則            類（第1〜3類）、特別管理物質 ※特化則に該当したときだけ聞きます
5  有機則・鉛則・粉じん則・化管法・毒劇法・消防法・化審法・
   大防法・水濁法・土対法・女性則
6  確認して登録      物質名・備考の入力と、答えた内容の一覧
```

### AIに聞くプロンプトをコピーする

SDSに書かれていない項目は、AIに聞いて調べられます。ウィザードに2種類のコピーボタンがあります。

| 場所 | ボタン | 内容 |
|---|---|---|
| 各法令の画面 | **この法令のプロンプトをコピー** | その法令だけを聞く。回答は「該当／非該当／わからない」の1行＋根拠 |
| 物質の特定・確認画面 | **全法令ぶんのプロンプトをコピー** | 21法令をまとめて聞き、**物質マスタの列名どおりのCSV**で返してもらう |

まとめて聞いたほうの回答は、`物質マスタ` タブの**「貼り付けて取り込む」**にそのまま貼れます。プロンプトには各列に入れてよい値（`該当` / `非該当` / `要確認`、特化則なら `第1類`…、消防法品名は全20品名の一覧）を書き出してあるので、取り込める形で返ってきます。

プロンプトには次の指示を必ず入れています。

- 確認できない場合は推測せず**「わからない」**と答えること。誤って「非該当」とされると法令違反を見落とすため
- 根拠とした**条文・別表・告示の番号と名称**を示すこと
- 令和6年4月1日・令和7年4月1日の対象物質追加を反映した最新の一覧で判断すること
- 最終的に人が官報・e-Gov法令検索・職場のあんぜんサイトで裏取りすること

まとめて聞くほうには「確認できなかった列は空欄ではなく `要確認` と入れること（空欄は非該当として取り込まれる）」も加えています。

**AIの回答をそのまま信用しないでください。** 根拠の条文を確認してから登録する前提の道具です。確信が持てないものは「わからない」のままにしておけば、要確認として残り続けます。

クリップボードが使えない画面（一部のサンドボックス環境）では、自動コピーの代わりに選択済みの枠が開きます。

**「わからない」は非該当にしません。** 値2（要確認）として記録し、その物質を使っている製品がある限り、法令該当判定の要確認欄に出し続けます。区分のあるもの（特化則の類、有機則の種別、化管法の種）は `?` として同じ扱いになります。

| 選択 | 記録される値 | 判定での扱い |
|---|---|---|
| 該当する | 1 | 該当。関係するタスクが出ます |
| 非該当 | 0 | 対象外 |
| わからない | 2（区分ありは `?`） | **要確認**。対象外とは判断しません |

CSVでも `要確認` として書き出され、取り込み直しても値が保たれます。

この画面が、いままで直接入力できなかった**備考**の入力先でもあります。SDSの発行日、供給者へ照会中の項目、判断の根拠を残しておくと、次に見る人が追えます。

## 資料をタブとして内蔵する

法令リファレンス（08）とSDS運用ガイド（09）は、台帳のタブとして中に入っています。別ファイルを開かなくても、判定を見ながら根拠を引けます。

```bash
python3 tools/build_checklist.py --mode web --out chem-checklist.html
python3 tools/build_guide.py     --mode web --out chem-guide.html
python3 tools/embed_docs.py      # chemical-compliance.html の <!-- EMBED:xxx --> へ差し込む
```

別々に作ったHTMLをそのまま入れると、CSSの `:root` や `body`、id名が台帳側とぶつかります。`tools/embed_docs.py` は取り込むときに次を機械的に行います。

| 処理 | 内容 |
|---|---|
| CSSのスコープ | 全セレクタを `#panel-ref` / `#panel-guide` の配下に限定。`:root` と `body` はパネル自身に読み替え、`:root[data-theme="dark"]` のようなテーマ指定は `:root[data-theme="dark"] #panel-ref` に組み替えます |
| idの改名 | `id="x"` を `id="rf-x"` / `id="gd-x"` にし、CSSの `#x`、JSの `"#x"` と `getElementById("x")` も同時に書き換えます |
| `@page` の除去 | 台帳側の用紙指定を上書きさせません |
| スクリプトの隔離 | 即時関数で包み、変数が台帳の外に漏れないようにします |
| 操作ボタンの非表示 | テーマ切替・保存・印刷は台帳側にあるため、埋め込んだ側は隠します |

**元のHTMLとPDFはそのまま残ります。** 単体で配りたいときはそちらを使ってください。

## SDS運用ガイド

成分が開示されない化学品を含む状態で、SDS第15項（適用法令）だけを手がかりに管理を回すための手順書です。全7章・付録3。

| 章 | 内容 |
|---|---|
| 1 | SDSのどこを見るか（16項目のうち判定に効く6項目） |
| 2 | 開示のレベルを3つに分ける（全成分／法令対象物質のみ／非開示） |
| 3 | 第15項の表記から照会項目へ（表記ゆれの対応表） |
| 4 | 法令名だけで確定する義務（10法令） |
| 5 | 供給者への聞き方（三段階＋法的に請求できる範囲） |
| 6 | 情報が埋まらないときの扱い |
| 7 | 年間の回し方 |
| 付録 | 裾切り値／記録の保存年数／照会状のひな形 |

```bash
python3 tools/build_guide.py --mode web   --out chem-guide.html
python3 tools/build_guide.py --mode print --out print.html
```

**裾切り値・記録の保存年数・照会項目は台帳の定義から機械的に取り出しています。** `chemical-compliance.html` の `DECL_ITEMS` と `TASKS` を読むため、台帳を更新すればガイドも再生成するだけで追従します。本文だけを直したいときは `tools/guide_content.py` を編集してください。

## アーティファクトに同梱して配る

claude.ai上で公開する場合、HTMLと一緒に次のファイルを同梱すると、**開いた時点で8,199物質の物質マスタが入った状態**になります。枠外への通信はCSPで遮断されますが、同じ場所に置かれたファイルは読めるためです。

| 同梱するファイル | 役割 |
|---|---|
| `chem-master.js` | 起動時に自動で読み込まれる物質マスタ（この分はブラウザに保存せず、開くたびに読み直します） |
| `chemical-compliance.html` | アプリ本体そのもの。「書き出し」タブから持ち帰れます |
| `chem-checklist.html` | 「書き出し」タブの**法令リファレンスをHTMLで保存**で取り出せます |
| `chem-checklist.pdf` | 同じく**確認点一覧をPDFで保存**で取り出せます |
| `chem-guide.html` / `chem-guide.pdf` | SDS運用ガイド。**SDS運用ガイドをHTMLで保存**で取り出せます |

### 実行ファイル一式をZIPで持ち帰る

「書き出し」タブの**「一式をZIPで保存」**で、上の6ファイルを1つの書庫にまとめて保存できます。展開してできたフォルダの `chemical-compliance.html` をダブルクリックすれば、同じ画面が手元で動き、物質マスタも同じフォルダの `chem-master.js` から自動で読み込まれます。

ZIPは外部ライブラリを使わず、ブラウザの `CompressionStream("deflate-raw")` でその場で組み立てています（使えない環境では無圧縮で格納）。実測で5.1MBが2.6MBになり、展開したファイルは元とバイト単位で一致します。

```bash
# 公開用のHTMLは doctype / html / head / body を外したものを使います
python3 tools/build_checklist.py --mode web --out chem-checklist.html
cp 化学物質関係法令_確認点一覧.pdf chem-checklist.pdf
```

社内サーバやローカルフォルダで使う場合も同じで、HTMLと同じ場所に置けば同じように働きます。同梱していない環境では内蔵マスタ211物質で起動し、保存ボタンはその旨を表示して何もしません。

リファレンス側にも**「HTMLで保存」**を付けてあります。外部ファイルを参照していないので、保存したものをそのまま社内で配れます。

## 位置づけ

法令の該当判定を機械的に行い、対応漏れを可視化するための実務ツールです。
最終的な適法性の判断、所轄官庁への確認、専門家（衛生管理者・作業環境測定士・危険物取扱者等）への相談に代わるものではありません。
