# despeckle.py — スキャン図面の点々ノイズ除去

青焼き・マイクロフィルム・古い紙図面のスキャンに乗る胡麻粒状のノイズを、
細線と手書き寸法文字を保ったまま落とすためのツール。

## 準備

```
pip3 install pillow numpy scipy
```

## 使い方

```
python3 tools/despeckle.py 図面.png -o 図面_clean.png
python3 tools/despeckle.py 図面.png -o out.png --level strong
python3 tools/despeckle.py 図面.png -o out.png --mode gray
python3 tools/despeckle.py 図面.png --preview 比較.png      # 処理前後を上下に並べて確認
```

まず `--preview` で当たりを見て、強度を `--level` で調整するのが早い。

## 処理の流れ

1. **背景ムラ補正** — grey closing で紙の地を推定し、除算で平坦化する。
   青焼き特有の濃淡ムラや退色を吸収する。
2. **二値化** — Sauvola 適応二値化に、大域しきい値によるゲートを掛ける。
   ゲートは既定で **3クラス大津法**。地汚れの多いスキャンでは通常の
   2クラス大津法は「地」対「粒＋線」で分けてしまい、しきい値が明るすぎて
   粒を拾う。3クラスに分けて「地／粒／線」の下側の境界を採ることで、
   粒を落としつつ薄い線を残す。
3. **ノイズ粒の除去** — 連結成分ごとに面積・外接矩形・縦横比・充填率を見る。
   ゴミ粒は「小さく・短く・べったり詰まっている」。細長い断片（切れた線）や
   スカスカな塊（文字の画）は残す。
4. **任意**：方向性オープニング、白抜け穴の充填、切れ線の closing。

## 主なオプション

| オプション | 既定 | 用途 |
|---|---|---|
| `--level {mild,normal,strong,max}` | — | 強度プリセット。個別指定が優先 |
| `--mode {bw,gray}` | `bw` | `bw`=1bit二値（軽い） / `gray`=濃淡を残しノイズだけ白く飛ばす |
| `--gate {otsu3,otsu2,none}` | `otsu3` | 大域しきい値の決め方 |
| `--gate-offset N` | `0` | しきい値補正。`-` で地汚れに強く、`+` で薄い線を拾う |
| `--min-area N` | `30` | これ以下の画素数の塊をノイズ候補にする |
| `--min-extent N` | `8` | 外接矩形の長辺がこれ以下のものだけ除去対象 |
| `--max-fill F` | `0.55` | 充填率がこれ未満の塊は残す（文字・線の保護） |
| `--keep-aspect F` | `3.0` | 縦横比がこれ以上の細長い塊は線断片として残す |
| `--bg-radius N` | `25` | 背景推定の半径px。線幅より十分大きく |
| `--window N` | `31` | Sauvola の窓サイズpx |
| `--directional N` | `0` | N px 以上いずれかの方向に伸びる構造だけ残す。粒が繋がって塊化した図面向け |
| `--fill-pinholes N` | `0` | 線内部の白抜けを埋める |
| `--close N` | `0` | 切れた線を繋ぐ（線が太る） |
| `--invert` | off | 白線／黒地の図面 |

## 解像度による調整

既定値は概ね 300〜400dpi のスキャンを想定している。
600dpi など高解像度では、粒も線も画素数が増えるため
`--min-area` `--min-extent` `--bg-radius` `--window` を概ね
解像度比の2乗／1乗でスケールさせる。

- 600dpi 目安: `--min-area 120 --min-extent 16 --bg-radius 50 --window 61`
- 200dpi 目安: `--min-area 14 --min-extent 5 --bg-radius 17 --window 21`

## 検証結果

実画像に近い合成テスト（2400x900、線・円・手書き相当の寸法数字60個に対し、
半径0〜2px の胡麻粒を被覆率12%で散布、加えて紙の濃淡ムラとガウスノイズ）での測定値。
「線残存」「文字残存」は正解マスクに対する再現率、
「ノイズ除去」は正解の線以外に乗った画素をどれだけ落とせたか。

| 設定 | 線残存 | 文字残存 | ノイズ除去 |
|---|---|---|---|
| `--gate otsu2`（3クラス化前） | 100.0% | 100.0% | 悪化（-39.6%） |
| `--level mild` | 99.2% | 93.0% | 65.2% |
| `--level normal`（既定） | 99.2% | 93.1% | 77.7% |
| `--level strong` | 97.8% | 80.3% | 88.9% |
| `--level max` | 93.9% | 44.6% | 93.7% |

2400x900 で約1秒。

注意: 合成テストは実スキャンの代用であり、実ファイルでの最適値は別途
`--preview` で確認すること。特に `strong` 以上は小さな手書き数字が欠ける。
