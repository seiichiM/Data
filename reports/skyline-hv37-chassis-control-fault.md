## 1. 「シャシー制御システム故障」の定義

**【事実・日産公式】**
V37スカイラインの取扱説明書（警告表示の項）には、次の記載がある。

> アクティブレーンコントロールに異常があると、システムが自動的にOFFになり、メーター内のディスプレイに「シャシー制御システム故障 取扱説明書を見てください」と警告メッセージが表示されます。

公式の一次対処は「安全な場所に停車し、ハイブリッドシステムを一旦停止してから再始動し、再びアクティブレーンコントロールをONにする」。復帰しなければ日産販売会社で点検、とされている。

**【推察】**
V37の「シャシーコントロールモジュール」は、アクティブレーンコントロール（ALC）／アクティブトレースコントロール（ATC）／アクティブエンジンブレーキ／アクティブライドコントロールを統括する制御ユニットである。これらは自前のセンサーを持たず、**車輪速（ABS/VDC）・舵角センサー・ブレーキスイッチ・エンジン／HV制御ユニットからのCAN信号**を材料に演算している。
したがって本メッセージは「シャシー制御モジュール本体が壊れた」ことよりも、**「入力信号のどれかが欠落／不整合になり、制御を続行できないので自らOFFした」という“結果表示”である確率が高い**。これが、原因が多岐にわたり、かつ他の警告灯（VDC、ABS、エンジン、ハイブリッドシステム故障）と同時点灯する事例が多い理由と考えられる。

## 2. 掲示板から抽出した実例と原因類型

### 類型A：ブレーキランプスイッチ（ストップランプスイッチ）— 最頻・最安

**【事実】**
- CARTUNE の V37 投稿（ユーザー K.Factory）：「エンジンつけたら、1分後くらいに、すぐ表示される」。当初は一時的に消えていたが、やがて常時表示に進行。**クルーズコントロールと各種センサー機能が使用不可**になった。
- 同投稿のコメントで、ユーザー MORIYU310 が「**運転席足元にあるブレーキランプスイッチ**が原因だった」と報告。ユーザー sugar も同症状を同部品で解決、「**2個で一万円しないくらい**」と費用を明示。
- 元日産ディーラー整備士（ユーザー takashi）は、診断機での確認に加え**ヒューズ点検**も推奨。
- **【訂正 2026-09-14】** 本レポート初版は、同投稿の写真に写り込んだ表示を「ボンネット開閉警告」と記述していたが、同一症状を呈する実車のオーナーからの指摘により、これは**前方監視センサーOFF**の表示であると訂正する。初版の記述は、ページを機械的に読み取った要約に基づくものであり、**写真そのものを画像として確認したものではなかった。** 前方監視センサーOFFは本症状に付随して出る表示群の一つであり、「別件の消し忘れ」として切り捨てるべきものではない。
- 別系統の作業実績（V37 200GT-t、車検・整備工場）：「モニターにシステム故障、メーターに ABS・横滑り（VDC）マーク・インテリジェントエマージェンシーブレーキ警告灯」が表示された車両が、**ブレーキランプスイッチ交換で解消**。

**【推察】**
V37はブレーキ系スイッチが複数接点（ストップランプ用／ブレーキ判定用）で構成され、両者の信号が食い違うと制御側が「ブレーキ状態が判定不能」と見なす。ALC・ACC・自動ブレーキ・VDCはいずれもブレーキ信号を前提に動くため、**1個の安価なスイッチ不良で「シャシー制御システム故障」＋ABS＋VDC＋IEBが一斉に出る**という広範囲の症状になる。
**最初に疑うべき、かつ最も安く済む候補。** 症状が「始動直後すぐ出る」「ACCが使えない」場合は特に確度が高い。

### 類型B：電源系 — 12V補機バッテリー劣化、ヒューズ断、電圧降下

**【事実】**
- HV37の**12V補機バッテリーはトランクルーム左側**に搭載。駆動用（リチウムイオン）と併せ2系統あるため、どちらの系統の問題か診断での切り分けが必要（日産FAQ／グーネット解説）。
- 英語圏フォーラムの集約（検索抜粋）：「12Vバッテリーがマージナル（弱り始め）になると、多系統にわたって奇妙な不具合が出る」「整備士がこれらのエラーを**低電圧**に起因すると判断した」。あるオーナーは**補機バッテリー交換＋コード消去**で復帰している。
- 同系統の別車種（セレナ C27 ハイブリッド）の整備手帳では、「シャシー制御システム故障」＋アイドリングストップ警告が出てエンジンがクランキングせず、原因は **"ELEC PARTS (IG POWER-3)" の10Aヒューズ断**。交換のみで復旧。投稿者の結論は「**エラー発生時はまずヒューズをチェック**」。

**【推察】**
シャシー制御・VDC・HV制御はいずれもIG系電源を共有する。電圧が一瞬でも閾値を割る、あるいは特定系統のヒューズが飛ぶと、CANノードが脱落して「通信途絶＝システム故障」と判定される。
**コストゼロ〜1万円で切り分けられるため、類型Aと並んで最優先で確認すべき。** 特に「複数の無関係な警告が同時に出る」「再始動で消える」パターンは電源系を強く示唆する。

### 類型C：エンジン本体（VQ35HR）— 冷間時失火・VTC・油圧低下／スラッジ【HV37初期型で最重要】

これがご質問の「エンジン本体の異常」に直結する類型で、**初期型HV37で最も報告が濃い**。

**【事実】** みんカラ Q&A「シャシー制御システム故障 エラーについて」（回答13件）より：

- 質問者（STすいか）の症状：**「シャシー制御システム故障」「VDC警告灯」「故障警告灯（CEL）」「ハイブリッドシステム故障警告灯」が同時に出る。特に冷えているときに出る。** 気温が高い日や十分暖機してから再始動すると消えることがある。エラー中はEVモードに入らない。
- 実施済みだが**未解決**：12Vバッテリー交換、イグニッションコイル交換。
- 回答者 mikiisallofme：**複数気筒のミスファイア（失火）コードを検出**。プラグとVTC交換でも治らず、**3週間の診断の末「片バンクの油圧低下」が原因と判明。フラッシング施工で完治。**
- 回答者 あがえこ：**DASにも不具合**があり再設定で一時改善。「ソレノイド・カム角センサー・クランク角センサーを交換しても無効なら、**スプロケット／タイミングチェーン／ギャラリーガスケット**を疑うべき」。さらに「**初期型のVTCソレノイドはメッシュ（ストレーナ）が詰まりやすく、現行の対策品では改善されている**」。
- 同氏の追報：VTCソレノイド4本全数＋カム角／クランク角センサーを交換したが、**運転席側バンクはVTCエラーが出るのに失火なし、助手席側は失火するのにエラーが出ない**という矛盾した挙動。
- 別ソース（VQ35HRの低温時不具合に関するQ&A）：VQ35HRのVTCは油圧制御であり、**低温で油粘度が上がるとソレノイド／アクチュエーターの動きが鈍り、バルブタイミング異常→失火**を招きうる。クランク角センサー異常も低温で信号不良を起こし失火要因となる。
- 中古車販売側の指摘（部品屋のウラ話）：V37購入前チェックとして**オイルフィラーキャップ裏のスラッジ堆積**を確認せよ。整備履歴不良のサインであり内部損傷に繋がる。

**【推察】** 以下が初期型HV37の典型的な故障連鎖と考えられる。

```
オイル管理不良／経年
        ↓
オイル通路・VTCソレノイドのメッシュにスラッジ堆積（初期型ソレノイドは特に詰まりやすい）
        ↓
片バンクの油圧低下 → VTC（可変バルブタイミング）が指令通り動かない
        ↓
バルブタイミング異常 → 失火（低温時に油粘度上昇で悪化＝「冷間時に出る」の説明がつく）
        ↓
エンジンECUが失火を検知 → トルク制限／フェイルセーフ
        ↓
エンジントルクが「制御の前提」を外れる
        ↓
VDC・シャシー制御・HV制御が演算不能 → 一斉に「システム故障」表示
```

**この連鎖が、「シャシー制御システム故障＋VDC＋CEL＋ハイブリッドシステム故障」が同時に出て、暖機後に消える現象を最もよく説明する。**
またイグニッションコイル交換・VTCソレノイド交換で治らなかった実例が複数あることは、**真因が電装品単体ではなく油圧側（＝オイル通路の詰まり）にある**ことを示唆する。mikiisallofme 氏の「フラッシングで完治」はその直接の裏付けである。

**【推察・対処優先度】**
1. オイル粘度が指定通りか確認（指定外の高粘度油は低温症状を悪化させる）
2. オイルフィラーキャップ裏／ロッカーカバー内のスラッジ目視
3. **油圧計実測（バンクごと）とデータモニタでの実バルブタイミング vs 指令値の比較**
4. 改善が見込めればフラッシング＋高頻度オイル交換
5. それでも駄目なら、タイミングチェーン／スプロケット／ギャラリーガスケット（オイル通路のシール抜け）を疑う

### 類型D：ハイブリッド系 — クラッチ、モーター、HV制御コンピュータ、駆動用バッテリー

**【事実】**
- みんカラ整備手帳（ユーザー shudou）：走行8.6万km、**8.4万kmでクラッチ交換済み**。ハイブリッドシステム故障警告＋異音＋変速時のスリップ感、**シャシー制御警告も同時発生**。ディーラーはオイルポンプとモーターを交換したが**未解決**、次に車間距離制御システムの交換を提案（ただし直る保証はないとの説明）。最終的に「**ハイブリッド制御コンピューターが駄目だったみたい**」で、交換ではなく**書き換え（リプログラム）で解決**。同氏の重要な指摘：**「停車状態の診断機では故障コードが拾えなかった」**（＝間欠故障）。
- みんカラQ&A一覧に「**何万kmぐらいでクラッチ交換されましたか？ 15万km以上で無交換の方いらっしゃいますか？**」という定番スレッドが存在＝クラッチは消耗・交換前提の部位として認識されている。
- Yahoo!知恵袋（V37 350GT HYBRID Type P、走行約8万km、10年落ち、2023年投稿）：走行中に「シャシー制御異常」表示 → ディーラー診断（診断料3〜4万円）で**駆動用バッテリー故障の可能性**と判定。**バッテリー交換80万円、総額約85万円**の見積。回答者も「15万km時点で同様の診断を受け、約100万円と言われた」と証言。
- 部品屋の解説：350GT HYBRIDはモーター／バッテリー／インバーター故障時の修理費が突出し、**バッテリー＋インバーター交換で82万円**の実例。
- 英語圏（Infiniti Q50 Hybrid、検索抜粋）：2014年式で**15mph以上でリンプモード、EV走行のみ**になり、ディーラーはトランスミッション交換に**2万ドル（部品1.6万＋工賃0.4万）**を提示。しかし**「ミッションのコードは偽コードで、実際の問題はシャシーコントロールモジュール側にあった」**という報告あり。
- 同フォーラム由来のDTC群：**P3185、C1B92、C1B93、C1A6E、C1A70、P0720、C1B90、P11AB、C1A04、C118C、U0104**。うち **C1A6E はハイブリッドシステム（インテリジェントブレーキ／回生ブレーキ、HPCM制御ユニット、配線）**、**P0720 は出力軸回転センサー不良**（速度情報の不整合→シャシー制御エラー＋モーター回転制限）、**U0104 は制御ユニット間通信途絶**系。
- 回生ブレーキ関連の注意：**HV専用でないブレーキパッドを装着すると回生協調制御に干渉し、シャシー制御エラーを誘発しうる**（英語圏フォーラムの指摘）。

**【推察】**
HV37は1モーター2クラッチ方式で、エンジンとモーターの間の乾式クラッチと、電動オイルポンプによる油圧制御が肝である。**クラッチのスリップや油圧不足は「駆動トルクの不整合」としてシャシー制御側にも波及する。**
重要なのは、**ディーラーが高額部品（ミッション、駆動用バッテリー）を提示した事例でも、実際はHV制御コンピュータの書き換えやシャシーコントロールモジュール側で解決した実例が国内外の両方に存在する**こと。数十万〜100万円の見積を提示された場合、**セカンドオピニオンと「制御ユニットの書き換え・学習値リセットを先に試したか」の確認は費用対効果が極めて高い。**

### 類型E：ABS／VDC車輪速センサー、舵角センサー、DAS（ダイレクトアダプティブステアリング）

**【事実】**
- 英語圏フォーラムの集約：「Chassis Control System Error は **VDCまたはABSの不具合**に関連することが多い。**車輪速センサー、ABSモジュール、および配線の損傷・腐食**を確認せよ」。
- 同：「**舵角センサー**はアクティブレーンコントロールおよびダイレクトアダプティブステアリングにとって不可欠であり、この異常がシャシー制御システムのエラーに繋がる」。
- 日産公式（DASの説明）：停車中や極低速でのステアリング反復操作、または保舵の継続により**DASが過熱して作動制限に入り、操舵が重くなる**。過熱を繰り返すと**システム故障に至る**。また**指定外サイズのタイヤ・ホイールではDASが正しく作動せず、パワーステアリング警告灯が点灯する**ことがある。
- みんカラ整備手帳（ユーザー happy37、V37）：先進安全装備のシステム故障が**2.5年で2回**発生。自動ブレーキ・ABS・ACCが同時に機能停止。**前回と今回で交換部品が異なった**。
- みんカラ整備手帳（ユーザー masasama2、V37 HV、2020年1月）：約1時間走行後に「システム故障」表示 → 再始動で消滅 → **ディーラー診断で異常検出できず、「再発したら調べる」**。

**【推察】**
社外ホイール・インチアップ・車高調装着車では、**タイヤ外径変化による車輪速の左右／前後不整合**がシャシー制御の演算を破綻させうる。カスタム歴のある個体では改造内容の確認が必須。
また happy37 氏・masasama2 氏の事例が示すように、**同一メッセージでも原因部品は毎回異なりうるし、間欠故障では診断機に痕跡が残らない**。「ディーラーで異常なし」は「異常がない」ことの証明にはならない。

## 4. 推奨診断手順（コスト昇順）

**【推察】** 実務上、以下の順で潰すのが合理的と考える。

**フェーズ0：無料**
1. 車台番号で**リコール・改善対策の実施状況**を日産に照会（DAS／ブレーキブースター／駆動用モーター）

## 6. 結論

**【事実として確認できたこと】**
1. 「シャシー制御システム故障」は日産公式にはアクティブレーンコントロールの異常表示であり、原因部位を特定するメッセージではない。
2. 国内掲示板で最も多く「解決した」と報告されている原因は**ブレーキランプスイッチ**（1万円未満）。
3. HV37初期型で最も重症かつ再現性の高いパターンは**冷間時にCEL・VDC・HV警告と同時発生するもの**で、実例では**片バンクの油圧低下**が真因、フラッシングで完治した。
4. 初期型のVTCソレノイドはメッシュが詰まりやすく、**現行の対策品では改善されている**との証言がある。
5. ディーラーが数十万〜100万円規模の部品交換を提示した事例で、実際は**制御コンピュータの書き換えで解決**した例が国内・海外の双方にある。
6. HV37初期型には DAS、ブレーキブースターポンプモーター、駆動用モーター制御プログラムのリコールがあり、いずれも本症状に直結しうる系統である。
7. 間欠故障のため、停車状態の診断機では故障コードが拾えない実例が複数ある。

**【推察としての総括】**
初期型HV37の本症状は、**単一原因ではなく「入力系のどこかが落ちた結果の共通表示」**と捉えるのが正しい。したがって診断は「部品を当てにいく」のではなく「入力信号を上流から潰す」順序で進めるべきである。
特に**「冷えているときに出る」という条件が付く個体は、電装ではなくエンジン側の油圧・スラッジ問題を第一に疑うべき**で、イグニッションコイルやVTCソレノイドの交換から入ると、実例のとおり費用だけかかって解決しない可能性が高い。

逆に、**「冷間条件と無関係」「始動直後すぐ出る」「ACCが使えない」個体は、まずブレーキランプスイッチとヒューズと12V補機バッテリー**を潰すこと。ここで解決すれば1万円台で済む。

> **【2026-09-14 追記】** 本章は掲示板情報のみに基づく一般論である。実車1台への適用例として、
> 正規診断機の結果と症状の聴取から原因を絞り込んだ事例を**第7章**に追記した。
> あわせて、**「始動直後すぐ出る」ことが必ずしもブレーキランプスイッチを意味しない**ことが同章で判明したため、
> 本章および第3章のマトリクスを読む際は第7章を併せて参照のこと。

本章は、本レポートの読者である実車オーナー（HV37前期、同症状を発症中）への8問のヒアリング結果と、それに基づく絞り込みである。
**【事実】= オーナーの申告および正規診断機の結果、【推察】= 筆者の推論、を従前どおり区別する。**

### 7.1 ヒアリング結果

| # | 質問 | 回答（【事実】オーナー申告） |

| 1 | 同時表示 | **前方監視センサーOFF**／**ハイブリッドシステム故障**／**ABS・横滑り（VDC）警告灯** |
| 2 | 発生条件 | **始動直後（数十秒〜数分）にほぼ毎回**。**気温が高い日でも出る**。**再起動を数回すると消える**。発症後はHVがOFFになり、**本来停止するはずのエンジンがアイドリングを継続**。その際に**エンジン警告灯が点滅した（1度）**。オーナー自身の観察として「日頃使わないアイドリング近辺の燃焼不調」を疑っている |

### 7.2 判定：VTC（可変バルブタイミング）系でほぼ確定

**【事実】** 正規診断機でVTC／カム角・クランク角センサー系のコードが検出されている。これは推測ではなく一次的な診断結果である。

**【事実】** P0011／P0021（吸気カムシャフトポジション過進角、Bank1／Bank2）の一般的症状は *hard start（始動不良）／degraded idle（アイドリング不調）／stalling（エンストする）* であり、オーナーが独自に観察した「アイドリング近辺の燃焼不調」と一致する。

**【推察】** 各手がかりの解釈は次のとおり。

| 手がかり | 解釈 |
|---|---|
| 始動直後 数十秒〜数分に毎回 | 油圧が立ち上がりきる前＝VTCが最も不安定な瞬間に一致 |
| **気温が高くても出る** | 単なる低温時の油粘度上昇による症状ではない。初版で想定した類型Cより**進行した段階**にある |
| 再起動を数回すると消える | 部品の完全な死ではなく、油圧不足または機構の固着による**間欠作動不良**の挙動 |
| 前方監視センサーOFF・ABS/VDC・HVシステム故障の同時表示 | エンジンが正常トルクを出せないことに対する各制御の**巻き添え**。表示は結果であり、根は1か所 |

### 7.3 「エンジンが止まらずアイドリングを続ける」ことの意味

**【推察】** 本件で最も重要な手がかりと考える。

VQ35HRのVTCには**始動用の最遅角ロックピン**がある。エンジン停止前にカムを最遅角へ戻してロックしなければ、次回始動時に正常な燃焼が得られない。**油圧不足または機構の固着によりロックが確保できないとECUが判断した場合、ECUは「今停止させると再始動できない」としてエンジン停止を禁止すると考えられる。**

HV車は本来アイドリングでエンジンが停止する。それが回り続けているのは、**ECUが意図的に停止させていない**挙動として説明がつく。「HVシステムがOFFになる」ことも同じ理由で整合する。

**【事実】** エンジン警告灯の**点滅**は、点灯とは意味が異なり、**触媒を損傷させるレベルの失火が進行中であること**を示す（メーカー横断の共通規格）。

**【推察】** 点滅が観測された回は、ロック不良のまま始動して実際に失火した瞬間と考えられる。**点滅中の走行継続は触媒（キャタライザ）の熔損を招き、修理費を一桁上げるリスクがある。**

### 7.4 対応段階と費用（このオーナー向け）

> **【2026-09-14 第2回改訂による注記】** 本節作成後、**この車両に指定外の 10W-40 が常用されていた**という事実が判明した。
> これにより**段階1の位置づけが「安いのでまず試す」から「最有力仮説の検証」に格上げ**されている。**7.7 を先に読むこと。**

**【推察】** 金額はいずれも一般的な相場からの推定であり、**検証済みの価格ではない。** 必ず見積を取得すること。

| 段階 | 内容 | 費用目安 | 位置づけ |
|---|---|---|---|
| **0** | **ディーラーから正確なコード番号を聞き出す**（P0011／P0021 か、P0340 系か等） | 無料 | **最優先。ここで交換部品が確定する** |
| **1** | 指定粘度の新油へ交換し、以後 5,000km／6ヶ月へ短縮。同時に**バンク別の油圧実測**と、データモニタでの**VTC指令値 vs 実測値**の比較 | 2〜4万円 | これで消えれば最良 |
| **2** | **VTCソレノイド交換**（吸気側のみか全数かはコード次第）。**必ず対策品番を指定する**（初期型はメッシュが詰まりやすく現行品で改善との証言あり／本レポート類型C参照） | 5〜12万円 | ここまでが「安く治まる」範囲 |
| **3** | カム角センサー・クランク角センサー交換 | 3〜8万円 | 段階2で不十分な場合 |
| **4** | タイミングチェーン／スプロケット／ギャラリーガスケット | **30〜60万円級** | **手放す判断ライン** |

**【推察】** 「安く治まるなら直す、高額なら手放す」という方針に対する線引きは、**段階3と段階4の間**にある。段階3までで解決すれば累計20万円台に収まるが、段階4に入ると金額が一段跳ね上がる。

### 7.5 本件が掲示板事例より有利な点

**【推察】**

1. **無駄玉を撃たずに済む。** 本レポート類型Cで引用した掲示板事例のオーナーらは、プラグ・イグニッションコイル・VTCソレノイドを交換して**なお解決せず**、3週間の預かりを経て油圧低下に到達している。本件は**12V補機バッテリー交換のみ**の段階で、かつ**正規診断機によるVTC系という当たりが既に出ている。**
2. **最悪ケースの想定が不要。** 走行6〜10万kmであり、検出コードの性質からも、駆動用バッテリー（80〜100万円）やクラッチが主因である可能性は低いと考えられる。

### 7.6 次のアクション

1. **触媒の保護を最優先。** エンジン警告灯が**点滅**している間は運転を避けるか、速度と負荷を落とす。点灯（消えない状態）であれば通常走行は可能だが、点滅は別扱いである。
2. **段階0：正確なコード番号を取得する。** P0011／P0021（バルブタイミング過進角）か P0340 系（カム角センサー）かで、交換すべき部品と金額が変わる。
3. 番号確定後、段階1→2→3の順で進め、段階4に到達した時点で費用対効果を再評価する。

### 7.7 使用オイルの粘度に関する検証【2026-09-14 追加／第3回改訂で位置づけ変更】

> **【位置づけの変更】** 本節は執筆時点で「最有力仮説」としていたが、その後 P0024 の判明により、

#### 7.7.1 判明した事実

**【事実・オーナー申告】** 常用している整備工場が **10W-40** を好んで使用している。

**【事実・日産公式FAQ】** HV37（ハイブリッド、2014/02〜2016/03）の指定は **5W-30**（API SM。2016/4以降はSN）。油量はオイルのみ約4.6L／フィルター同時交換時 約4.9L。交換時期は通常 1年/15,000km、**シビアコンディション 6ヶ月/7,500km**。

> **要注意：同じV37でも、ガソリン車は 0W-20（2019/9以降）／0W-30（2014/6〜2019/8）であり、ハイブリッドだけが 5W-30 である。**
> 「V37スカイライン＝0W-20」として作業されると、逆方向に柔らかすぎる誤りとなる。**0W-20 でも 10W-40 でもなく、5W-30 が正解。**

**【事実・SAE J300】** 10W-40 は 5W-30 に対し、低温側・高温側の**両方で高粘度**である。

| | 5W-30 | 10W-40 |
|---|---|---|
| 100℃の動粘度 | 9.3〜12.5 cSt（SAE 30） | **12.5〜16.3 cSt（SAE 40）** |
| 低温側 | 5W（10Wより厳しい低温流動性要件を満たす） | 10W（5Wより硬い） |

**【事実】** 10W-40 は 40℃・100℃のいずれにおいても 5W-30 より高粘度である。

**【事実】** VTC（可変バルブタイミング）は**油圧とソレノイドバルブで作動**し、ソレノイドのプランジャーが油路を切り替えて制御する。この方式である以上、**オイルの粘度と状態は決定的な要素**である。

#### 7.7.2 機序

**【推察】** 粘度は嗜好の問題ではなく**制御パラメータ**である。日産は油路断面積、ソレノイド応答特性、ECUの制御ゲイン（指令から何ミリ秒でカムが何度動くかという前提）を、**5W-30 を前提に設計・適合**している。

重要なのは、**粘度が上がると油圧は上がるが、細い通路を通る流量は減る**という点である。VTCのカム位相を素早く振るのに必要なのは圧力ではなく**流量**である。

```
油が硬い → 細い油路とソレノイドを通る流量が減る
        ↓
カム位相が指令値に追従できない（応答遅れ）
        ↓
ECU「指令角度に到達していない／ずれている」と判定
        ↓
P0011 / P0021（バルブタイミング異常・システム性能）
```

「硬いオイルのほうが油膜が強くて安心」という直感は、**滑り軸受には当てはまるが、油圧アクチュエータには逆に働く。**

#### 7.7.3 決定打：HV37は油温が上がらない

**【事実】** ハイブリッド車の油温は、**一般道走行中で約40℃、高速道路でようやく60℃程度**という非常に低い水準にとどまる。

**【推察】** ここが本件で最も効く。通常のガソリン車なら油温は90〜110℃に達し、そこでは 10W-40 も設計意図に近い粘度域に入る。**しかしHV37はその温度に到達しない。**

> **この車に 10W-40 を入れると、オイルは常に「硬い領域」に留まり続ける。**
> 粘度のズレが「冬の朝だけ」ではなく、**通年・走行中も継続する。**

#### 7.7.4 症状との照合

**【推察】** 既知の手がかり4点が、いずれも粘度仮説で説明される。

| 症状 | 粘度仮説による説明 |
|---|---|
| 始動直後 数十秒〜数分に出る | 油温が最も低く 10W-40 が最も硬い瞬間。VTC応答が最も遅い |
| 再起動を数回すると消える | わずかな油温上昇で粘度が許容範囲に入る |
| **気温が高い日でも出る** | **10W-40 は高温側でも硬い。**余裕が季節を問わず食われている |
| アイドリング近辺で不調 | 低回転＝オイルポンプ吐出量が最小＝流量不足が最も顕在化する領域 |

**この3番目が決定的である。** 「冷間時だから」という説明では、気温が高い日にも発生することを説明できなかった。**粘度仮説はこれを説明する。** 初版第2章の類型C（低温時の油粘度上昇）を、本節が上書き・一般化する形になる。

#### 7.7.5 副次経路：フィルターバイパス

**【推察】** 冷間始動時に硬いオイルを流すと、オイルフィルター前後の差圧が上昇し、**フィルターのバイパスバルブが開く。** その間は**濾過されていないオイルが油路へ直行する。**

すなわち 10W-40 は、VTCの応答を鈍らせるだけでなく、**VTCソレノイドのメッシュを詰まらせる異物を運ぶ経路**も開きうる。「初期型ソレノイドはメッシュが詰まりやすい」という掲示板の証言（類型C）と、悪い意味で噛み合う。

#### 7.7.6 整備工場の判断について

**【推察】** 10W-40 を好む工場には相応の理由がある。過走行エンジンの保護、オイル消費の抑制、メカノイズ低減、そして**1種類のドラムで多車種をまかなえる**という現実的事情である。多くの旧世代エンジンでは悪い選択ではない。

ただし**VTC付きエンジン、かつ油温が上がらないハイブリッドという組み合わせでは、最も悪い方向のズレとなる。** 悪意ではなく車種特性とのミスマッチである。

#### 7.7.7 期待と注意

**【推察】期待できること**
- これが主因なら、**指定油に戻すだけで改善する。** 考えうる最も安価な結末である。
- これから行うオイル交換が、**単なる整備ではなく特定仮説のA/Bテスト**になる。

**【推察】注意すべきこと**
1. **長年 10W-40 で走行していた場合、既にスラッジやメッシュ詰まりが進行している可能性がある。** その場合、油種是正の効果は部分的にとどまる。
2. **硬いオイルは摩耗した軸受の油圧低下を覆い隠す。** 5W-30 に戻した直後に油圧が低く出たとしても、それは**交換が壊したのではなく、これまで隠れていた実態が露出しただけ**である。数値として記録すること。

### 7.8 燃料系からオイル系への経路の評価【2026-09-14 追加】

#### 7.8.1 検討した仮説

**【事実・オーナー申告】** 過去に1度だけ、満タン時に適正量の **AZ FCR-062**（燃料添加剤）を投入したところ、**低回転域のぎくしゃく感が解消した**。時期は本件症状との前後関係を含め不明。

オーナーからの問い：この添加剤が燃焼室へ噴射され、ピストンリングを経由してオイルパンへ侵入し、**オイルパン内のスラッジを剥離させた**可能性はあるか。

#### 7.8.2 評価：経路は存在するが、濃度が2〜3桁足りない

**【事実】** FCR-062 は**燃料添加剤**であり、洗浄主成分は高濃度の **PEA（ポリエーテルアミン）**。作用対象は**インジェクター／吸気ポート／吸気バルブ／燃焼室（ピストン頂部）**のカーボン・スラッジ・ワニスであり、溶けた汚れは燃焼して排気から排出される。

**【事実】** ハイブリッド車では頻繁な始動停止により**燃料希釈が発生しやすい**。したがって未燃焼燃料がピストンリングを越えてオイルパンに達する経路は、この車では常時機能している。**添加剤成分がオイルパンに到達すること自体は起こる。**

**【推察・概算】** ただし濃度が問題になる。**仮説に有利な（濃いめの）前提**を置いて試算する。

```
仮定1: 添加剤の混合比を 1:500（かなり濃いめの想定）
仮定2: 燃料希釈率を 5%（かなり悪い側の想定）
仮定3: オイル量 4.6L（HV37の指定量）

オイルに混入した燃料      = 4,600ml × 5%   = 230ml
その中の添加剤            = 230ml × 1/500  = 約0.46ml
オイル全体に対する濃度    = 0.46 / 4,600   = 0.01%（約100ppm）
```

一方、エンジンオイルには**清浄分散剤（カルシウム系清浄剤・コハク酸イミド系分散剤等）が元から数％＝数万ppm配合されている。**

**オイル側に元から入っている洗浄成分の 1/100〜1/1000 量が追加されるにすぎない。** 悪い側に振った前提でこの数字であり、実際はさらに小さい。

**【推察】** さらに、汚れの種類と温度域が異なる。PEAの設計対象は**高温の燃焼室・吸気バルブに焼き付いた炭素系デポジット**であり、オイルパンのスラッジは**酸化重合油＋水分＋すす**という別種の汚れである。しかも油温は 40〜60℃であり、PEAの設計領域外である。

実際にオイルパンへ落ちるものの主体は「PEA」ではなく「ガソリン」であり、ガソリンは軽いワニスは溶かすが硬化スラッジは溶かさない。**最大の実害は剥離ではなく粘度低下である。**

**【推察】時系列** 大量のスラッジが剥離してストレーナやVTCメッシュを閉塞したのであれば、投入直後〜数百km以内に**悪化**するはずである。実際に起きたのは**改善**であった。ただし投入時期が特定できないため、この論拠は弱く扱う。

**結論（推察）：考えにくい。ただし完全にゼロとは言えず、事後的な証明も反証も不可能である。** そして**いずれであっても次の行動は変わらない**——抜いたオイルとフィルターの現物が答えを持っている。

#### 7.8.3 副産物として得られた診断情報

**【推察】** 「FCR-062 で低回転域のぎくしゃく感が解消した」という事実自体は、**低回転域の不調の一部が実際に燃料系・吸気系のデポジットに由来していた**ことを示す信頼できる証拠である。オーナー自身が立てた「主原因とは別の副原因としてアイドリング近辺の燃焼不調がある」という読みを裏付ける。

VQ35HR はポート噴射とされ（社外インジェクターが「2ジェットタイプ」として流通していることが傍証）、**PEA系添加剤が吸気バルブ裏を直接洗える構造**である。直噴エンジンより添加剤が効きやすい。

**再投入は安価な診断テストとして有効だが、条件が3つある。**
1. **順番はオイル交換が先。** 現在入っているオイルが燃料希釈の証拠物件であり、先に燃焼を改善させると証拠が薄まる。
2. **VTCは治らない。** 一時的な症状軽減が、VTCの問題と触媒のリスクを見えにくくする危険がある。改善しても「治った」と判断しないこと。
3. **適正量を守る。** 濃くしても洗浄力は頭打ちで利点がない。

#### 7.8.4 本命の機序：燃料希釈のループ

**【推察】** 燃料系からオイル系への影響として実際に警戒すべきは、スラッジ剥離ではなく**燃料希釈**である。

```
低回転での燃焼不調・失火
        ↓
未燃ガソリンがシリンダー壁を伝ってオイルパンへ（燃料希釈）
        ↓
オイルの粘度が低下
        ↓
油圧低下
        ↓
VTCが指令位置を保持できない
        ↓
バルブタイミング異常 → さらに失火  ← 最初に戻る（自己増殖ループ）
```

**これは掲示板事例の「片バンクの油圧が低い」という診断結果を、スラッジ堆積とは別に説明しうる。** もしこちらが真相なら、詰まりの洗浄ではなく**燃焼の正常化によって油圧が回復する**ことになる。

#### 7.8.5 HV特有のスラッジ生成機序

**【事実】** ハイブリッド車のオイル劣化について、次が指摘されている。

| 事実 | 帰結 |
|---|---|
| 始動停止を頻繁に繰り返すため**燃料希釈が発生しやすい** | オイルが薄まる |
| 油温が低い（一般道約40℃、高速で約60℃） | — |
| **水分は100℃近くにならないと蒸発しない**ため、水分がエンジン内に溜まり続ける | 水＋酸化油＋すす＝スラッジの材料が揃う |
| 劣化オイルは**油路を詰まらせ、オイルポンプの動きを阻害する** | **「片バンク油圧低下」の機序そのもの** |

**【推察】** スラッジ生成の本線はこちらである。**1回の燃料添加剤より、「ハイブリッドという使われ方 × 10,000km／1年という交換間隔」の積み重ねのほうが、要因としてはるかに大きい。** 日産がシビアコンディションを 6ヶ月/7,500km と定めていることと整合し、**HV37の使われ方は実質シビアコンディション側に寄っている**と考えるべきである。

**【推察】剥離リスクの正しい警戒先** 燃料添加剤ではなく**オイル側のフラッシング剤**である。あちらは希釈されず直接オイルパンで作用するため、スラッジを一気に浮かせてストレーナを閉塞させる現実的リスクがある。初版第2章で「強力なフラッシング剤ではなく新油の短サイクル交換から入る」と述べた理由はこれである。

### 7.9 オイル交換を診断機会として使う手順【2026-09-14 追加】

**【推察】** オイル交換を「消耗品交換」で終わらせると、得られるはずの情報を捨てることになる。同じ入庫で以下を実施する。

#### 7.9.1 交換前・交換時の確認

| 確認項目 | 読み取れること |
|---|---|
| **伝票・交換ステッカーで「何を・いつから」入れていたか特定** | 10W-40 が何年・何万km分だったか。**7.7 の期待値を左右する** |
| **抜く前に油量を点検：FULLより多い** | **燃料希釈の典型。**燃え残りが溜まって増えている |
| **抜いたオイルがガソリン臭い** | 同上。**最も簡便で確実な判定法。必ず匂いを確認する** |
| 抜いたオイルがシャバシャバで粘りがない | 粘度低下。指定粘度の手触りではない |
| 抜いたオイルの油量が減っている | オイル消費。これはこれで別の手がかり |
| **抜いたオイルを容器に受けて目視** | スラッジ・金属粉の有無。**捨てたら二度と見られない** |
| **オイルフィルターを切開または内部を目視** | 詰まりの証拠が最も出やすい場所 |
| **油圧の実測（できればバンク別）** | 車が上がっている今が最も安い。**最大の付加価値** |

整備工場に任せる場合も「**抜いたオイルを見せてください、匂いを確認したいので**」と事前に伝える。

#### 7.9.2 交換仕様

- **5W-30（API SN または SP）** — 0W-20 でも 10W-40 でもない
- **フィルター同時交換**（約4.9L）。詰まったフィルターを残すと新油の意味が薄れる
- **強力なフラッシング剤は入れない**（7.8.5 参照）。新油の短サイクル交換で穏やかに
- 以後は**シビアコンディション基準（6ヶ月／7,500km）**で運用する

整備工場への説明は「好みの問題ではなく、**VTCという油圧制御機構の設計前提**であり、しかも**ハイブリッドは油温が上がらない**」と伝える。

#### 7.9.3 観察プロトコル

**【推察】** 間欠故障であるため、**記録がなければ「改善した」のか「たまたま出なかった」のか判別できない。** 2週間程度、冷間始動のたびに以下を記録する。

- 日付・**外気温**
- 表示が出たか／出たなら**始動から何秒後か**
- **何回再始動で消えたか**
- **エンジン警告灯の点滅の有無**（最重要）
- アイドリングが継続したか、正常にエンジンが停止したか

#### 7.9.4 判定基準

| 観察結果 | 解釈 | 次の手 |
|---|---|---|
| **改善（頻度低下・再始動回数減少）** | **粘度仮説（7.7）を支持。**安く済む道が濃くなる | 対症ではなく前提是正なので継続。段階2へ進むかは症状の残り方で判断 |
| **全く変わらない** | 油の問題ではなく**機械的な詰まり・固着** | 段階2（対策品ソレノイド）、場合により段階4（チェーン系）へ |
| 改善するが完治しない | 粘度と機械的要因の複合 | 段階2へ。ただし油種是正の効果分だけ予後は良い |

**いずれの結果でも無駄玉が1つ減る。** 判定不能に終わることがないのが、この手順の利点である。

#### 7.9.5 優先順位についての注意

**【推察】**
1. **段階0（正確なコード番号の取得）は無料で電話1本。** オイル交換の予約と同時か、それ以前に済ませる。番号が分かった状態で観察に入れば、2週間を無駄にしない。
2. **エンジン警告灯が点滅している間は走行を控える。** オイル交換と観察に2週間を使う間に触媒を焼くと、節約したはずの金額が吹き飛ぶ。

### 8.1 確定した事実

| 項目 | 内容 | 出所 |
|---|---|---|
| **故障コード** | **P0024** | 日産ディーラー CONSULT |
| **診断機の日本語表示** | **「エキゾーストVTC B2 異常」** | 同上 |
| SAE汎用定義 | "B" Camshaft Position - Timing Over-Advanced or System Performance (**Bank 2**)。"A"＝吸気、"B"＝**排気** | SAE／各DTC資料 |

| 走行距離 | 6万〜10万km | オーナー申告 |
| 使用オイル | **10W-40**（指定は 5W-30） | オーナー申告 |

**【事実】** 日産CONSULTの日本語表記とSAEのコード定義は**別系統の命名体系**であり、その両方が「排気側・バンク2」を指している。解釈の余地はない。

### 8.2 原因の絞り込み

**【推察】** 排気側VTCが油圧作動である以上、P0024 の原因は次の2系統に絞られる。

```
P0024（排気VTC B2 異常）
├─ A：ソレノイド本体の不良
│     電磁コイルの断線・劣化、スプールの固着
│
└─ B：そのソレノイドに供給される油の問題
      ├─ メッシュ（ストレーナ）の詰まり  ← 初期型ソレノイドの持病
      ├─ 粘度過大（10W-40）による流量不足
      ├─ 油面過多によるエアレーション（気泡混入 → 油圧が伝わらない）
      └─ 油圧そのものの不足
```

**AとBは排他ではなく、併発している可能性が高い。**

**【推察】4系統（2バンク×吸排気）のうち、なぜ排気B2だけが落ちたのか**

粘度過大は4系統すべての余裕を削る。**もともと最も余裕の少ない1系統が、最初に閾値を割る。** 排気B2がその最弱点だったと考えられる。したがって「粘度は無関係」でも「粘度だけが原因」でもなく、**局所的な弱点 ＋ 全系統の余裕減少の複合**と読むのが妥当である。

### 8.2a 「放置日数依存」という決定的な症状特性【第4回改訂で追加】

**【事実・オーナー申告】数日乗らないと再発しやすく、乗った日は再発しにくい。**

**【推察】これは本件で最も強い手がかりの一つである。** 症状を支配する変数が、**気温ではなく「前回運転からの経過時間」**であることを示す。

```
従来の理解 : 気温が低いと出る（ただし気温が高い日にも出るため、説明しきれなかった）
正しい理解 : 前回運転からの経過時間が長いと出る
```

**これにより「気温が高い日でも出る」が完全に説明される。** 気温ではなく、その日がたまたま数日ぶりだったということである。

#### 合致する機序（2つ。いずれも同じ対処に収束する）

**機序B-1：オイルのドレンダウンと再充填の遅れ**

```
数日放置
   ↓
シリンダーヘッド上部の油路・VTCアクチュエータ内のオイルが
オイルパンへ落ちて空になる（ドレンダウン）
   ↓
始動時、その空間を油で満たし直す必要がある
   ↓
通路やメッシュが詰まっている／油が硬い（10W-40）と再充填に時間がかかる
   ↓
その間、カム位相が指令に追従できない → P0024
   ↓
数分走れば満たされ、以後は正常

前日に乗っていれば油が残っているので即座に満たされる → 出ない
```

**機序A-2：ソレノイドのスプール固着**

ソレノイド内部のスプール（弁体）が、数日動かないままワニスや汚れで固着し、初回作動で引っかかる。一度動かせば以後は動く。**これも「放置すると出る／乗っていれば出ない」に一致する。**

#### 除外できる候補

**【推察】「数日乗れば症状が消える」性質を持たない故障は、候補から外れる。**

| 候補 | 判定 |
|---|---|
| **タイミングチェーン伸び／スプロケット／位相器本体の摩耗** | **除外寄り。**機械的な狂いは放置時間で変わらない。**＝30〜60万円の分岐が消える** |
| 電磁コイルの断線・劣化 | **除外寄り。**電気的不良は放置時間に左右されない |
| 配線・コネクタ不良 | **除外寄り。**振動や熱で出るもので、放置では変わらない |
| カム角センサー不良 | **除外寄り。**同上 |
| **ソレノイドのスプール固着（A-2）** | **合致** |
| **油路・メッシュの詰まり、粘度過大（B-1）** | **合致** |

**残ったのはいずれも、本計画（排気側B2ソレノイド交換 ＋ オイル是正）で対処できるものである。高額修理の線が一段薄くなった。**

#### ① ディーラーには「数日寝かせてから診断」を必ず伝える

**修正版の観察方法**

| ☐ | 内容 |
|---|---|
| ☐ | オイル交換後、**意図的に2〜3日（以前に再発した間隔と同じだけ）乗らない期間を作る** |

| ☐ | **前回運転からの経過時間（日数・時間）を必ず記録する** ← 最重要の新規項目 |

### 8.7 エンジン警告灯が点滅した場合の対応

**【事実】** 警告灯には3つの状態があり、意味が異なる。

| 状態 | 意味 | 走行 |
|---|---|---|
| **点滅** | 触媒を傷めるレベルの失火が**今まさに起きている** | **停止** |
| **点灯（点きっぱなし）** | コードが記録されている。異常は検出済みだが進行中ではない | **低負荷なら可** |
| 消灯 | 数回の走行サイクルを経て自己消灯した状態 | 可 |

**【重要】確定した失火コードが記録されると、警告灯は「点灯」に変わり、異常が再発しない走行サイクルを3回繰り返すまで消えない。** したがって——

> **判断基準は「完全消灯」ではなく「点滅が止まったかどうか」である。**
> 点滅 → 点灯 に変われば、低負荷での移動は可能。完全消灯を待つ必要はない。

**対応手順**
1. 点滅に気づいたら**アクセルを踏まず、回転を上げず**、惰性で安全な場所へ寄せる（失火の激しさは負荷に比例する）
2. 停止し、しばらく置いてから再始動
3. **点滅が止まって点灯または消灯になれば、低負荷で移動してよい**
4. **再始動2〜3回で点滅が止まらなければレッカー。**それ以上粘らない（狂ったタイミングでの始動自体が失火の機会になる）
5. **自分でコードを消さない。**点滅した回のフリーズフレームデータはディーラーが読むべき情報である
6. 発生時の**速度・回転数・走行状況・外気温**を記録する

**【推察】本件でのリスク評価** 点滅は**1度のみ、短時間で、次の始動時には消灯**していた。確定コードとして記録されるまで至らなかったことを示唆し、**触媒への実害はほぼないと考えられる。** 通常の使用に支障はない。上記手順は「万一の再発時」用として保持しておけばよい。

| **再発の閾値** | **1.5日（約36時間）の放置で発症**（2026-09中旬・温暖期） | 「数日」より短い。**ドレンダウンが速い**＝進行を示唆。温暖期に閾値が縮むという 8.2a の予測とも整合 |
| **始動時の異音** | **数日放置後の冷間始動で、ボンネットを開けて確認。異音なし** | **位相器の機械的ガタは考えにくい**（後述の限界あり） |
| **オイルのガソリン臭** | **なし** | **燃料希釈は否定。**油面がアッパー超なのは「入れすぎ」の可能性が高い |
| **オイルの汚れ** | ゲージ上で薄茶、6,800kmにしては**きれい** | 低油温でポリマー熱劣化が進まないためと考えられる。**重度の汚染はない** |
| **フィラーキャップ裏** | 粉体状の微小カーボンが軽度のみ。乳化なし | 重度スラッジ・冷却水混入ともになし |
| **オイルフィルターの交換履歴** | **前回同時交換されたか記憶にない** | 「2回に1回」運用なら**16,000km以上使用**の可能性。**下記 9.2 参照** |
| スパークプラグ | 35,000kmで購入以降**無交換**（新車装着の可能性） | P0024の原因ではないが、**失火の余裕**に影響。10万km毎の定期交換部品 |

### 9.2 オイルフィルター履歴不明が持つ意味

**【推察】** 日本では「オイル交換2回に1回エレメント」という運用が広く行われている。仮にそうであれば、現在装着のフィルターは **16,000km／1年半以上**使用している可能性がある。

これは議論してきた3つの経路すべてを強める。

| 経路 | 古いフィルターの影響 |
|---|---|
| **アンチドレンバックバルブ** | ゴムの硬化・へたり → **停止中のドレンダウンが加速** → 「1.5日で発症」の説明力が上がる |
| **バイパスバルブの開弁** | ろ紙の目詰まり → **未濾過油が油路へ直行** → ソレノイドのメッシュへ異物を供給 |
| 濾過性能 | 捕集能力の低下 |

**「オイルはきれいなのにメッシュが詰まった」という一見の矛盾は、フィルターがバイパスしていれば説明がつく。**

**【推奨】** この車では、**オイル交換のたびにフィルターも同時交換する**。低油温で水分と汚れが抜けず、かつドレンダウン依存の症状を抱えているため、一般車以上に意味がある。

### 9.3 検討し、除外または限定した仮説

**【推察】**

| 仮説 | 結論 |
|---|---|
| **流路の曲がりによる遠心分離で、粒子がバンクに偏る** | **成立しない。**ストークス数の概算で約 10⁻⁴（有意な分離には ≳0.1 が必要）。オイル中では粒子との密度差が約1.5倍しかなく、粘度が空気の数千倍。粒子は流線に完全追従する |
| バンクごとの油路的な不利 | **見当たらない。**P0011／P0014／P0021／P0024 の4コードすべてが市場で報告されている。偏っていれば特定コードに集中するはず |
| 曲がりが堆積に関与する | **成立しうる。**ただし遠心ではなく**下流のよどみ域での堆積**として。左右非対称の理由にはならない |
| 停止中の沈降による偏り | **否定できない。**沈降速度の概算で約3.5μm/秒 ＝ 3日で理論上0.9m。時間スケールが症状と一致する。**ただし未検証** |
| **位相器（駆動部）の機械的摩耗** | **考えにくい。**最良条件（数日放置後の冷間始動、モーター介入なし、室が空）で打音なし。加えてHVは低回転高負荷をモーターが担うため、位相器が叩かれにくい |
| 位相器の**油圧的**不良（チェックバルブ・シール） | **除外できない。**無音で進行するため、異音の不在では判定できない |
| マニュアルモードでの低回転高負荷試験 | **実施不可。**HV37のATは不適正なギアを受け付けない（ラギング保護） |
| D/Rでのブレーキ＋アクセル（ストール試験） | **禁止。**トルコンがなくクラッチ直結のため、クラッチを焼く。P/Nなら安全だが負荷がかからず無意味 |

### 9.4 「シャシー制御システム故障」という表示について

**【推察】** 実態を正確に表すなら「**条件不成立**」または「**作動停止**」である。シャシー制御は壊れておらず、動作に必要な前提（正常なエンジントルク）を得られずに自ら停止しているにすぎない。

**【事実】** 日産の取扱説明書自身の対処法が「**停車し、ハイブリッドシステムを一旦停止して再始動し、再びアクティブレーンコントロールをONにする**」であることは、**メーカー自身が条件不成立として扱っている**ことを示す。

**【推察】** 「故障」と表記するのは、運転者に行動（点検に出す）を促すためで、安全側への配慮としては合理的。ただし代償として、**原因が足回りにあるという誤解を広く生んでいる**（第2章の類型A、および調査中に確認したブログの例）。

### 9.5 「手を入れない」という選択肢の評価

**【事実】OBD検査の対象は2021年（輸入車は2022年）以降の新型車**であり、**2014年式のHV37は対象外**。特定DTCによる車検不合格の仕組みは適用されない。また「警告灯の点灯だけで車検の合否を判定するのは適当でない」という考え方も示されている。

**【推察】放置を支える材料**
- エンジン警告灯が点きっぱなしにならない（確定故障として成立していない）
- 点滅は1度きり、次回始動で消灯 → 触媒への実害はほぼない
- 再始動で復帰し、走行に支障がない
- 車検に影響しない

**【推察】それでも修理を勧める理由**
1. **安全装備の間欠的な停止。** 症状発生中は ABS・VDC・前方監視センサー（自動ブレーキ）が同時に停止する。気づかず走り出せば、その走行中ずっと支援がない状態になる
2. **進行している。** 閾値が「数日」→「1.5日」に短縮。詰まりは自然に改善せず、費用も待って下がらない

**【打ち切りの合図】様子を見る場合でも、次のいずれかが起きたら修理へ。**

| ☐ | |
|---|---|
| ☐ | エンジン警告灯が**点きっぱなし**になる |
| ☐ | **点滅が再発**する |
| ☐ | **再始動を繰り返しても消えなくなる** |
| ☐ | **閾値が1日を切る／毎回出る**ようになる |
| ☐ | 走行中の不調、異音など新しい症状 |

### 9.6 決定した方針（オーナー判断）

```
① オイル交換（定期交換時期として実施。全合成 5W-30・フィルター同時・規定量4.9L）
        ↓
② 意図的に数日空けて、再現するか観察
        ↓
③ 再発するなら、時期をみてソレノイド交換
```

**オーナーの判断基準：** 大急ぎではない。**車の持つ性能を気持ちよく発揮させるならやったほうがよく、性能を生かさないならこの車である必要がない**という割り切り。

**【推察】方針の評価：妥当。** 費用の安い順、かつ後戻りしない順に並んでいる。段階を飛ばしていない。

**ただし期待値：** 抜く前のオイルにガソリン臭がなく、汚れも軽度であったことから、「汚れたオイルが原因」という経路の説得力は下がっている。**②で再発する可能性のほうが高い。** それでも①に意味があるのは、粘度（10W-40→5W-30）の是正が独立して有効であり、②の結果がどちらでも次が決まるためである。

### 9.7 実行メモ（ディーラー／整備工場へ持参する内容）

#### オイル交換時に伝えること
- **5W-30（API SN または SP）・全合成**／**フィルター同時交換**／**規定量 約4.9L**
- **フラッシング剤は使用しない**
- **診断・故障コードには触らない**（バッテリーも外さない）
- **「前回、エレメントも交換されていましたか。記録を見せてください」**

#### オイル交換時に見せてもらうもの
- 抜く前の油量／**抜いたオイルの状態**（色・粘り・異物）
- **古いフィルターの内部**（異物の堆積）
- **古いフィルターのアンチドレンバックバルブ**（ゴム弁の硬化・変形）
- 可能なら**油圧の実測値を記録**（5W-30に換えた後の数値。「規定内」ではなく数値で）

#### ディーラーに伝える症状
- **エキゾーストVTC B2（P0024）単独**
- **1.5日の放置で再発。乗った日は出ない**
- **数日放置後の冷間始動で、ボンネットを開けて確認したが異音なし**
- オイルを5W-30・規定量へ是正済み

#### ディーラーに聞くこと
- **「この症状について技術情報（サービス情報／TSB）は出ていますか」**
- **「日産の技術相談に上げていただけませんか」**（放置日数依存という特徴は、現場で再現しにくく、技術部門にとって価値がある）
- 「P0024以外にコードは出ていますか。P0011／P0021 は」
- **「気筒別の失火回数を見せてください」**（バンク2の3気筒に偏っていれば因果が数字で裏付けられる）
- **「この症状は数日乗らないと出ません。2〜3日置いた状態で、冷間始動の瞬間から診断機をつないで見てください」**

#### 交換作業時の依頼
- **品番は現行の 23796-ZE02D で**（ZE01D は旧品番）
- **外したソレノイドのメッシュを見せてください**
- **その奥の油路側にスクリーンがあれば、そちらも確認・清掃を**
- 交換後の**学習（リラーン）**を実施

#### 観察記録の項目
- **前回運転からの経過日数**（最重要）／**気温帯**／始動何秒後に出たか／再始動何回で消えたか／CEL点滅の有無
